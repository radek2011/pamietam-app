# Pamiętam — PWA 1.0

Polska aplikacja do pielęgnowania relacji z bliskimi. Dane zapisywane są lokalnie na urządzeniu; nie publikuj kopii kontaktów w publicznym repozytorium.

## Funkcje
Ręczne dodawanie kontaktów, import VCF, przypomnienia po otwarciu aplikacji, historia kontaktów, telefon, WhatsApp i SMS, kopia zapasowa JSON. Wspierane urządzenia mogą udostępnić wybór kontaktu z książki telefonicznej.

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Adres: https://radek2011.github.io/pamietam-app/

## Ważne ograniczenia
Brak powiadomień push przy zamkniętej aplikacji. Dane w localStorage mogą zostać utracone po wyczyszczeniu danych przeglądarki — eksportuj kopię zapasową. Nazwa nie została prawnie zweryfikowana jako znak towarowy.
